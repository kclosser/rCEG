## ENVIRONMENT REPAIR — 2026-09-11
# numpy 1.26.4 was installed under Python 3.14.0, a combination with no
# upstream support (numpy added 3.14 wheels only in 2.3.x). Symptom:
# np.nanvar() silently returned 0.0 for every column of any array larger
# than roughly 400,000 elements, while np.var() stayed correct. Arrays
# below ~200,000 elements were unaffected, which is why it escaped notice.
# sklearn's VarianceThreshold calls np.nanvar internally, so every
# descriptor-matrix pipeline raised 'No feature meets the variance
# threshold'. Silent corruption of large-array reductions was possible.
# Repair: numpy upgraded 1.26.4 -> 2.5.3. Verified nanvar==var across
# shapes up to 5000x1000. Pre-repair pip freeze preserved alongside.
