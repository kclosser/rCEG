## 9. New results answering specific reviewer objections

### 9.1 "The model is not structure-only" (Reviewer 4)

| Configuration | features | MAE (eV) | Δ vs full |
|---|---|---|---|
| `full` | 427 | 0.3384 ± 0.026 | — |
| `drop_x0_x4` | 422 | 0.3385 ± 0.025 | +0.0001 (+0.0%) |
| `drop_x2_x4` | 424 | 0.3390 ± 0.026 | +0.0006 (+0.2%) |

**The objection is answerable.** Removing all five PQR scalars changes test MAE by +0.0001 eV (+0.0%), far inside the ±0.026 eV split-to-split SD. Inference on a new molecule needs only its SMILES string.

Caveat that must travel with the claim: training labels are calibrated pseudo-labels derived from `pqr_gap`, a semiempirical quantity. The result licenses a statement about **inference**, not about training. Full detail in SI §S10.

### 9.2 Geometry sensitivity

| Quantity | Value |
|---|---|
| Molecules attempted | 50 |
| Converged | **37** |
| Mean &#124;Δ gap&#124; | **0.440 eV** |
| Median &#124;Δ gap&#124; | **0.279 eV** |
| SD / max | 0.607 / 3.591 eV |

⚠️ **This is the most consequential new number in the revision.** The mean geometry-induced shift (0.440 eV) **exceeds the model's own test MAE (0.338 eV)**. Two things follow:

1. Accuracy should be quoted to **one decimal place** — 0.3 eV, not 0.338 eV. The third digit is not meaningful when the choice of input geometry moves the answer by more than the error itself.
2. The paper must state that its accuracy is conditional on the UFF-optimized geometry the pipeline consumes.

Only 37 of 50 optimizations converged, and the failures bias the estimate in both directions (SI §S7.2). Report with sample size and caveats attached.

### 9.3 Conformational floor

Median within-molecule gap SD across 9,697 molecules with ≥3 conformers: **0.076 eV** (IQR 0.028–0.160). This is irreducible noise for any model that sees one conformer.

### 9.4 Cross-protocol label floor

On the 14 molecules labelled under both QM9 and Psi4 protocols, mean absolute disagreement is **0.295 eV** (median 0.276, max 0.680). The manuscript's 0.295 eV is confirmed. Two defensible reference protocols disagree by about the same amount as the model's error, which bounds what any model trained on the mixture can achieve.

### 9.5 Reference pool arithmetic (Reviewer 2)

1,228 QM9-overlap + 909 Psi4-recomputed − 14 dual-labelled = **2,123**, consistent with the split sizes 1,274 + 425 + 424 (identical in all ten repeats; membership varies, sizes do not). ⚠️ **The manuscript's 2,137 is wrong** and appears in several places; all must be corrected.

### 9.6 Leakage audit

All 427 features against four leakage-relevant targets: largest absolute correlation anywhere is **|r| = 0.534**, and **5 features** exceed |r| = 0.5. None approaches the |r| = 0.94 excision threshold. Full table in SI §S3.

### 9.7 Open-shell agreement

PQR and DFT agree poorly on open-shell molecules: r = **0.074** over 99 molecules, against r = 0.694 for 660 neutral closed-shell molecules. This is the mechanism behind `charged_or_radical` being the weakest domain — a property of the input data, not of the learner, which is a stronger position for the paper than it sounds.

⚠️ The submitted draft cites "0.2 eV" in this context. That value matches no quantity computed here (the mean absolute difference is 8.3 eV). See `DISCREPANCIES.md`.

### 9.8 Descriptor identity and interpretability

All 375 LASSO-block descriptor names were recovered. ⚠️ **176 of them (47%) are Morgan fingerprint bits**, not named physicochemical descriptors. Any claim that the selected feature set is chemically interpretable must be narrowed accordingly.

The defensible interpretability claim is narrower and survives: **0 of the 5 learned breakpoints falls on a Morgan bit** — all five are named descriptors (TPSA, Hall–Kier alpha, BCUT2D, Ipc, VSA_EState). SI §S5.

### 9.9 External validation on QMugs

| Evaluation | MAE (eV) | R² |
|---|---|---|
| strict frozen transfer | 4.188 | -14.53 |
| 5-fold cross-fit, offset-aligned | **0.521** | 0.600 |

On 9,753 held-out QMugs molecules, excised by SMILES before fitting. Applied frozen the model does not transfer; once the protocol offset is estimated on held-out folds it reaches 0.521 eV. The honest reading — which should be stated as a limitation — is that rCEG transfers in ranking and shape but not in absolute placement, and a new reference protocol needs a handful of labelled anchors to re-align.
